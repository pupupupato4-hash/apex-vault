# APEX VAULT — Frontend Starter

รวมหน้า UI จาก Google Stitch ให้เป็นเว็บหลายหน้าและเชื่อม navigation เบื้องต้น

## Pages
- `/index.html` — Home / Marketplace
- `/pages/lucky-draw.html` — Random / Lucky Draw
- `/pages/topup.html` — Wallet Top Up
- `/pages/profile.html` — Profile / History
- `/pages/product.html` — Product / Checkout
- `/pages/success.html` — Order Success
- `/pages/vault.html` — Credential Vault
- `/pages/admin.html` — Admin Console UI

## Important
ชุดนี้ยังเป็น Frontend/Prototype ไม่ใช่ระบบขายของจริงเต็มรูปแบบ
ยังต้องเชื่อม Backend + Database + Auth + Server-side wallet/order/random logic ก่อนใช้งานจริง
